cpu_v2 ISA (v2.6) · Instruction Encoding & Hardware Control Signals

16-bit fixed-length instructions, 4 nibbles [n3 n2 n1 n0] (n3 = highest). 16 registers r0–r15; r13 = ra (link register, hardwired for all calls), r14 = sp, r15 = compiler temp. Flags G(bit0)/E(bit1)/L(bit2), set by cmp; condition test = |(flags & mask). Immediates: u4/u8 unsigned, i4/i8 signed; addi's i4 is zero-less (raw 0..7 → +1..+8, raw 8..f → −8..−1).

Port discipline: write addr = n0, read A = n1, read B ∈ {n2, n0}; r13/r14 in port columns are hardwired (implicit). Columns: Rd A / Rd B = register-file read-port address sources; Wr = write-port address; B src = ALU second operand; Mem; flags; PC = next-pc source. Defaults: PC = pc+1, no mem access, no flags write, single cycle.
