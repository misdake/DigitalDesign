Playground

    
Edit one rcc source file, then compile it directly into an in-memory debugger session.

    
Ctrl+Enter compiles and switches to the debugger. The Editor tab keeps the source available for another build.

    
Disable Optimize to preserve ordinary scalar locals in stable frame slots for debugger inspection.

    
Calls controls the call_abs function table. Auto selects repeated or hot call targets only when useful.

    
mod name; is intentionally unavailable here. The embedded rcc standard library is still linked normally.
