1. Architectural overview

16general-purpose, writable 16-bit registers
65,536word offsets in each boot-selected segment
1 or 2physical words per retired operation; two when PFX12 is consumed
CMP → Ba transient pending test result links a compare to its consuming branch; there are no persistent flags

Core rules

  • All arithmetic wraps modulo 216.
  • Memory is word-addressed; one address selects one 16-bit word.
  • A physical address directly concatenates a 16-bit segment and a 16-bit offset.
  • Reset starts with CSEG = DSEG = PC = 0; applications normally keep their boot-selected segments fixed.
  • The PC normally advances before instruction semantics, so relative control flow is based on the following word.
  • All registers are architecturally writable. ABI reservations are compiler conventions, not hardwired registers.
  • CMP-class instructions leave a transient pending test result (Less/Equal/Greater). Only a conditional branch or conditional move consumes it; any other retired non-prefix instruction expires it, and PFX12 is transparent to it. Reset leaves no pending result.
  • SIGNAL rs, 0 halts execution and latches rs as the architectural halt signal; nonzero signal types retire as a NOP in hardware.

Design intent

  • Small decoding surface: the high nibble selects the major operation.
  • A single transient pending test result, not persistent flags, carries a comparison outcome to its consuming branch.
  • Short immediates stay compact; PFX12 extends only explicitly listed consumers.
  • Near 16-bit pointers keep compiler data compact while segment registers form full physical word addresses.
  • Opcodes 0xC/0xD/0xE start the two-word signed Q16.16 FPU v2 (vector, scalar, and aux).

The encoding covers devices 0..7, each with channels 0..15. Device access is independent of memory and DSEG: only DEVRECV/DEVSEND reach devices, while LOAD/STORE always reach memory. The relative offset is signed i8 relative to the already-incremented PC (±128 words). With PFX12 the offset widens to off16 = {payload12[7:0], imm8}: the prefix's low byte supplies the high byte and payload12[11:8] is ignored. Conditional branches and conditional moves consume the pending test whether or not the branch is taken or the move writes, and fault InvalidInstruction without one — reported at the prefix address when prefixed. Register forms (functions 8..F) never consume a prefix. Reset leaves no pending result.

The pending test result is a transient three-way ordering (Less/Equal/Greater) set only by the CMP-class instructions CMPS, CMPU, CMPSI, and CMPUI. Any other retired non-prefix instruction expires it, and PFX12 is transparent to it. JALREL/JALR link to the architecturally fixed r14; compiler-generated wide control flow uses the canonical prefix with a 16-bit wrapping relative offset.

4.8 FPU v2 — opcodes C, D, E

Every FPU v2 instruction is 32 bits fetched as two consecutive 16-bit words and never consumes PFX12. All F registers are signed Q16.16 (16 fractional bits, range about [-32768, +32767.99998]) and every operation wraps: no saturation and no exception output. A vector is a consecutive register-range view, not an architectural type. The wide accumulator is signed 64-bit Q32.32: each product is exact, accumulation keeps the low 64 bits, and DOTSTORE takes ACC[47:16] from that wrapped sum.

opcodeLayoutSummary
Cword0: 0xC Fa Fb · word1: Fd len subop modeVADD, VSUB, VMUL, VMULS, VMIN, VMAX, VABS, VNEG, VFLOOR, VCEIL, VROUND, VTRUNC, VMOV, DOT, DOTADD, DOTSTORE; len 00/01/10 = vec2/3/4; DOT mode[1:0] selects stride 1/3/4.
Dword0: 0xD Fa Fb · word1: Fd subop modeADD, SUB, MUL, MIN, MAX, ABS, NEG, FLOOR, CEIL, ROUND, TRUNC, CMP, RCP, RSQRT, SINCOS, MOV; CMP writes the pending test; SINCOS mode[1:0] selects sin+cos / sin / cos.
Eword0: 0xE X Fa kind · word1: Fd subop modekind 00: FLD, FST, ILO2F, IHI2F, FLO2I, FHI2I, I16TOF, FTOI16. FLD/FST move two words per register, low half first; mode[1:0] + 1 gives the vector length.

Rounding is frozen as round-half-up (floor(x + 0x8000), ties toward +infinity); FLOOR clears the fraction, CEIL adds a unit when a fraction remains, and TRUNC is toward zero. RCP(0) returns 0x7FFFFFFF and RSQRT(x) is zero for x ≤ 0. All F registers are caller-saved and ACC is caller-clobbered; the compiler ABI reserves F0..F3 for returns, F4..F27 for arguments, F28..F62 for allocation, and F63 for parallel-move cycles. The v3 geometry library (v3_length2, v3_normalize, v3_distance_gt and their _checked debug variants) is a compiler library, not opcodes, lowered to existing FPU v2 instructions: v3_length2 is one DOTSTORE, v3_normalize adds RSQRT plus a scalar-vector VMULS (a zero vector stays zero), and v3_distance_gt is VSUB, one DOTSTORE, the ordinary distance approximated as s * RSQRT(s), then the scalar CMP against the ordinary Q16.16 threshold. The release helpers emit no checks and assume a small-range Q16.16 contract; the _checked variants validate it and halt with a fixed nonzero signal (1 length2, 2 normalize, 3 distance input, 4 distance difference) instead of clamping. Length/normalize require every component within [-104, +104] Q16.16; distance requires every input component within [-16384, +16383] so the 32-bit subtraction cannot overflow, then every difference component within [-104, +104] before DOTSTORE. The single DOTSTORE narrowing and the RSQRT/MUL approximation make the ordinary-distance boundary approximate.

5. PFX12 and wide operations

Canonical 16-bit immediate

F abc    A3 3 d

PFX12 0xabc followed by LDUI r3, 0xd loads r3 = 0xabcd. The pair is one precise architectural operation and retires two physical words together.

Closed consumer set

LOAD, STORE, MULI, every defined major-A operation except LDC/ADDC, and the major-B relative forms (functions 0..7) consume a pending prefix.

Integer imm4 consumers form value16 = {payload12, imm4}; relative off8 consumers form offset16 = {payload12[7:0], imm8} and ignore payload12[11:8] without a canonical-value fault.

Register ALU, register/immediate shifts and register multiplies, LDC/ADDC, the major-6 family, device instructions, conditional moves, register jumps, the FPU, reserved encodings, and another prefix do not consume it.

A prefix is transparent to the pending test result: a PFX12 sitting between a CMP-class producer and its consuming branch neither sets nor expires the test.

Precise prefix rule: a non-consumer expires the pending prefix and retires it separately. A second prefix also retires and replaces the first. If a prefixed consumer faults, the reported address is the prefix address and neither word retires.

6. Segmented addressing and ABI memory map

Physical address rule: physical_word = {segment[15:0], offset[15:0]}. There is no segment addition and a wrapping offset never carries into the segment. A fitted target may implement a smaller physical range and must report an error rather than truncate or alias an unsupported address.

Address-space contract

  • Ordinary CPU pointers cover one 65,536-word = 128-KiB segment.
  • Instruction fetch uses {CSEG, PC}; ordinary data and stack accesses use {DSEG, offset}.
  • All offsets, including 0xff00..0xffff, select ordinary memory in DSEG. Devices 0..7 are accessible only through the dedicated device instructions.
  • CompilerOptions::default() selects data base 0x4000, heap base 0x8000, and stack top 0x10000, encoded as SP = 0. CPU V3 has no v2.6 function table.
  • The CPU V3 compiler's optional code_base relocates all linked code offsets and function pointers without padding the emitted section bytes.

9. Revision history

RevisionChange
0.8Current. Breaking integer rearrangement with no binary compatibility. Majors 0/1/3/4/5 keep ADD/SUB/AND/OR/XOR; the old three-register MUL (major 2) and register-count SHL/ASR (majors 6/7) move into the destructive shift/multiply family at major 2, joined by SHR, the immediate shifts SHLI/SHRI/ASRI and MULI (both moved from major A), and the unsigned product windows MUL8/MUL16. Major 6 becomes the extended/system family (unary, bit queries, SEQ, destructive SLT/SLTU, pending-test CMPS/CMPU, SIGNAL, special registers, JSEG); NOP is now 6000. Major A keeps arithmetic/logic, constant construction at functions 2/3, and comparisons, with CMPEQI renamed SEQI; functions 7/B are LDC/ADDC, indexing a shared symmetric 16-entry constant table (MAG = [8, 16, 24, 32, 64, 128, 256, 512]; indices 0..7 hold MAG[k], indices 8..15 hold -MAG[k - 8]) that starts just past the 0..=15 range ADDI/LDI/LDUI already cover, and they never consume PFX12. Amendment (still revision 0.8): ADDI/SUBI read the unprefixed immediate as an unsigned u4 (0..=15) instead of a signed i4 — negative adjustments are SUBI's job, so the signed range wasted half the encodings; the PFX12-widened forms still add/subtract the full 16-bit immediate pattern. Major B becomes the symmetric control family: six conditional branches (0..5), JREL (6), JALREL (7), six conditional moves (8..D), JREG (B E 0 target), and JALR (B F E target), with JALREL/JALR linking to the fixed r14. 0.6Removes address-mapped device access; LOAD/STORE always reach memory.
0.5Replaces test-register branches with a transient pending test result, moves relative jumps into the B family, turns opcode C into device instructions, and frees r15 for general allocation.
