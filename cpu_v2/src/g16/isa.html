1. Architectural overview

16general-purpose, writable 16-bit registers
65,536word addresses shared by code, data, stack, and MMIO
1 or 2physical words per retired operation; two when IMMHI12 is consumed
0 flagsbranches test a register directly; comparisons produce 0 or 1

Core rules

  • All arithmetic wraps modulo 216.
  • Memory is word-addressed; one address selects one 16-bit word.
  • The PC normally advances before instruction semantics, so relative control flow is based on the following word.
  • All registers are architecturally writable. ABI reservations are compiler conventions, not hardwired registers.
  • HALT has no encoded signal register; the architectural halt signal is r0.

Design intent

  • Small decoding surface: the high nibble selects the major operation.
  • No condition-code dependency between comparison and branch.
  • Short immediates stay compact; IMMHI12 extends only explicitly listed consumers.
  • One address space simplifies the compiler while split caches preserve FPGA throughput.
  • Opcode 0xD remains reserved for a future FPU family.

2. Hardware organization

Normative target organization. The host cache and scheduler models implement these policies. The current board RTL validates the highlighted physical path but is not yet a reusable, complete core; see implementation status.

6. IMMHI12 and wide operations

Canonical 16-bit immediate

F abc    AF 3 d

IMMHI12 0xabc followed by LDUI r3, 0xd loads r3 = 0xabcd. The pair is one precise architectural operation and retires two physical words together.

Closed consumer set

LOAD, STORE, immediate functions 0..4, 8..B, E..F, all valid branches, and relative jumps consume a pending prefix.

Shift-immediate, extended/control, register ALU, reserved encodings, and another prefix do not consume it.

Precise prefix rule: a non-consumer expires the pending prefix and retires it separately. A second prefix also retires and replaces the first. If a prefixed consumer faults, the reported address is the prefix address and neither word retires.

7. Unified memory map and cache policy

Address-space contract

  • The CPU-visible range is exactly 65,536 words = 128 KiB.
  • The Tang Nano 20K contains more physical SDRAM; bank switching or a wider physical-address mechanism is intentionally deferred.
  • r15 normally holds 0xff00, so device/channel MMIO is emitted as a normal load/store with a small offset.
  • CompilerOptions::g16() selects data base 0x4000, heap base 0x8000, stack top 0xff00, and disables the legacy v2.6 function table.

Call sequence

Frame layout after allocation

Offset from current SPContents
0 .. saved-1Actually used callee-saved registers; a non-leaf function includes r14.

The prologue subtracts the complete frame size from r13, then stores saved registers. The epilogue reloads them, adds the frame size, and jumps through r14.

Direct calls currently use deterministic two-word wide relative linking. Indirect calls place the target in r12 and execute JALR r14, r12.
